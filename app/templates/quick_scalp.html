What this is: a deterministic strategy -- no AI model, no judgment call -- built for quick, small trades. Entries fire on EMA9/EMA21 crossovers confirmed by RSI(14), checked every 1 minute (no LLM in this loop, so no reason to run it any slower). A fixed 5% target and a fixed 3% stop, no trailing, and any trade that hits neither within 15 minutes is squared off regardless of P&L -- "quick" enforced on both price and time.

What this is not: validated. The entry signal (EMA_RSI_CROSS) and the cost-floor check this strategy would need to clear (scripts/scalp_breakeven.py) were both built on 10 Aug 2026 and never run against real data. Trailing was deliberately left out -- this project's own history has two separate findings against it at this scale: an earlier holdout test where a similar trail capped winners early while losses ran to the full stop, and a documented noise-hit risk at tight stop distances like this one's 3%. Paper trading only -- no live-order code path exists for this strategy.
