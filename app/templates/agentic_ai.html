What this is: a brand-new, isolated fifth strategy (25 Oct 2026), built as a set of specialized agents rather than one prompt doing everything -- entry, exit, risk/sizing, logging, backtest/QA, and news, each its own agent. OpenAI-only by explicit choice, with its own independent configuration below -- never the shared Settings > AI row AI Origination and Autonomous AI both read, so tuning one can never silently change the other (the exact confusion the gpt-6-luna reasoning_effort episode exposed on that shared row). Structurally paper-only -- no live order path exists anywhere in this module, same construction as every other experimental strategy in this project.

What exists right now: the backtest/QA agent, pointable at any existing strategy's real trade history; the logging agent, a scheduled cross-strategy daily digest; the risk/sizing agent (a deterministic pre-entry gate and position-size calculator, below); and a TRUE multi-agent entry/exit pipeline (rebuilt 25 Oct 2026) -- a Technical & Flow Agent (its own candle-fetch orchestration feeding EMA regime, ADX, chop efficiency, recent price action and PDH/PDL distance into its own directional lean), a News & Sentiment Agent (its own structured BULLISH/BEARISH/NEUTRAL read of real recent India-market headlines from free RSS feeds, not just a flat text dump), and a Master Orchestrator Agent that combines both verdicts into the final decision -- three independent model calls per index per cycle instead of one, deliberately chosen over a cheaper combined-call design for the extra signal fusion it buys. A separate, deterministic "severe event" kill switch blocks all new entries and force-closes every open position the instant a genuine black-swan headline (war, bank run, trading halt, ...) is detected -- before any of the three agents is ever asked. All three agents only ever decide direction (a lean, or BUY_CE/BUY_PE/NONE, or EXIT/HOLD) -- stop, target, position size, and the news kill switch are all computed deterministically, never by any model call.
